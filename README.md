# lucianapaes.github.io

Portfolio site, published with GitHub Pages at https://lucianapaes.github.io.

## Structure

```
index.html            the whole site (EN/PT, all case studies)
img/                  case study screenshots and the cover photo
icons/                favicon variants referenced in <head>
favicon.ico           kept at the root: browsers request it there
apple-touch-icon.png  kept at the root: iOS requests it there
.nojekyll             serves files as-is, without Jekyll
```

New images go in `img/` and are referenced as `img/name.png` in `index.html`.
